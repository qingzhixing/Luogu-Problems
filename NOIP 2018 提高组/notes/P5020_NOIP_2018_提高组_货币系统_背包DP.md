# P5020 [NOIP 2018 提高组] 货币系统

## 题目信息

题目链接：[https://www.luogu.com.cn/problem/P5020](https://www.luogu.com.cn/problem/P5020%E2%80%B8)

难度：普及+ / 提高-

算法标签：数学 贪心 背包DP 动态规划

## 题目大意

给定一个正整数数组 a，求解一个最小的正整数数组 b，使得能用 a 中元素的任意多倍的 和 凑出来数 与 能用 b 中元素的任意多倍的 和 凑出来数相同，求这个 b 的大小。

## 我的思路

一开始我是想找 a 中元素的最小公约数, 后来经过一番思索发现如果想和 a 能表示出来的数字一样，那么 b 一定要是 a 的子集，因为两个不同的数的倍数数列不同。

然后可以从小到大枚举 a 中的元素，如果当前元素能被已选择的元素表示，那么则跳过它，否则选中它。

如何判断能被表示？我一开始想到的是之前的解二元一次不定方程时的经验，我想解多元不定方程，然后判断根是否为正。但是这个貌似是 NP 完全问题，就不能这么做。

## 算法思路

根据 DeepSeek 提示，实际上我们按照题目条件，数字的任意多倍组合起来能表示的数可以用一个完全背包模型来等效替换。

- 令 dp[i] 表示是否能被表示，dp[0] = true;
- 从小到大枚举 a 中元素 ai，
- 如果 dp[ai] = true 则跳过；
- 如果 dp[ai] = false 则 push 进 selected，然后用当前 ai 去筛后面的数字
- 最终答案就是 selected.len()

```Rust
fn solution(tokens: &mut SplitAsciiWhitespace) {
    let n: usize = next(tokens);
    let mut a: Vec<usize> = (0..n).map(|_| next(tokens)).collect();
    a.sort_unstable();

    let mut selected = Vec::<usize>::new();
    // dp[i] 表示值为 i 的数字可以被已选数字表示出来
    let mut dp = vec![false; MAX_M];
    dp[0] = true;

    // 判断 a 中数字能否被选中
    for num in a {
        // 已能被表示，跳过
        if dp[num] {
            continue;
        }

        selected.push(num);

        // 状态转移
        // 用当前数字筛后面的数字
        for nxt in num..MAX_M {
            if dp[nxt - num] {
                dp[nxt] = true;
            }
        }
    }

    println!("{}", selected.len());
}
```

## 复杂度

时间复杂度：O(t * n * m)

空间复杂度：O(m)

## 触发点

- 判断某些元素的任意多倍加起来是否能凑成另一个数可以使用 **完全背包问题求解**
